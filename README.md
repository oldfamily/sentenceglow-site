# sentenceglow-site

Public pages for the Sentenceglow app, served with GitHub Pages from the `main` branch root.

| Page | URL |
| --- | --- |
| Landing | https://oldfamily.github.io/sentenceglow-site/ |
| Support (App Store / Play support URL) | https://oldfamily.github.io/sentenceglow-site/support |
| Privacy policy (store privacy URL) | https://oldfamily.github.io/sentenceglow-site/privacy |

Plain static HTML with one shared `style.css`; no build step. `.nojekyll` keeps GitHub from
running Jekyll. The privacy policy text is the same as `docs/store/privacy-policy.md` in
the app repo (`oldfamily/grammar-arena`); update both together.
